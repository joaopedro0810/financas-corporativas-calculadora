Juros Simples

J = C · i · n  |  M = C + J  |  C = M / (1 + i·n)  |  n = (M/C − 1) / i
Taxa e prazo em escalas diferentes? O prazo é convertido automaticamente (proporção linear). O campo calculado fica travado e se atualiza sozinho.

Juros Compostos

M = C · (1 + i)ⁿ  |  J = M − C  |  C = M / (1 + i)ⁿ  |  n = ln(M/C) / ln(1 + i)
Taxa e prazo em escalas diferentes? A conversão usa expoente — nunca multiplique/divida uma taxa efetiva diretamente. O campo calculado fica travado e se atualiza sozinho.

Sistema Price

PMT = PV · i / (1 − (1+i)⁻ⁿ)  |  PV = PMT · (1 − (1+i)⁻ⁿ) / i — parcelas constantes. Se a taxa estiver numa escala diferente da parcela (ex.: taxa anual, parcelas mensais), a conversão para a taxa equivalente da parcela é automática. Carência > 0 adia o início das parcelas — os juros do período podem capitalizar (aumentam o saldo) ou ser pagos à parte (saldo não muda).
