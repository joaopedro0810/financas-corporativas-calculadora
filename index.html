Juros Simples

J = C · i · n  |  M = C + J  |  C = M / (1 + i·n)  |  n = (M/C − 1) / i
Taxa e prazo em escalas diferentes? O prazo é convertido automaticamente (proporção linear). O campo calculado fica travado e se atualiza sozinho.

Juros Compostos

M = C · (1 + i)ⁿ  |  J = M − C  |  C = M / (1 + i)ⁿ  |  n = ln(M/C) / ln(1 + i)
Taxa e prazo em escalas diferentes? A conversão usa expoente — nunca multiplique/divida uma taxa efetiva diretamente. O campo calculado fica travado e se atualiza sozinho.

Sistema Price

PMT = PV · i / (1 − (1+i)⁻ⁿ)  |  PV = PMT · (1 − (1+i)⁻ⁿ) / i — parcelas constantes. Se a taxa estiver numa escala diferente da parcela (ex.: taxa anual, parcelas mensais), a conversão para a taxa equivalente da parcela é automática. Carência > 0 adia o início das parcelas — os juros do período podem capitalizar (aumentam o saldo) ou ser pagos à parte (saldo não muda).

Fluxo de Caixa — VPL, TIR, TIR-M, Payback e ILL

VPL = Σ CFₜ / (1+i)ᵗ  |  TIR: i tal que VPL = 0  |  ILL = VPL / Investimento — monte o fluxo completo (período 0 = investimento inicial, normalmente negativo; os demais períodos podem ser positivos ou negativos, em qualquer ordem).
Adicionar vários de uma vez:
TIR-M (Taxa Interna de Retorno Modificada / MIRR)
Usa duas taxas: uma para financiar as saídas de caixa e outra para reinvestir as entradas — mais realista que a TIR quando essas taxas são diferentes. Reaproveita o mesmo fluxo acima.

Perpetuidade

PV = FC₁ / (i − g) — fluxo de caixa perpétuo, com ou sem crescimento constante (modelo de Gordon). Deixe g = 0 para uma perpetuidade simples. Exige i > g. Informe o investimento inicial (opcional) para obter o VPL do projeto como um todo.

Capital de Giro (NCG)

PME = 360 × Estoques / CMV  |  PMR = 360 × Duplicatas a Receber / Vendas a Prazo  |  PMP = 360 × Fornecedores / CMV  |  Ciclo Operacional = PME + PMR  |  Ciclo Financeiro = Ciclo Operacional − PMP  |  NCG = Desembolso Anual × (Ciclo Financeiro / 360)

Ponto de Equilíbrio

Operacional = CF / (Preço − CV)  |  Contábil = (CF + Depreciação) / (Preço − CV)  |  Econômico = (CF×(1−IR) + Prestação − IR×Depreciação) / ((Preço − CV)×(1−IR)) — Prestação é o custo de capital do investimento anualizado (Sistema Price).
